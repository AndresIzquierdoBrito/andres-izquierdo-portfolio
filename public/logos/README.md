# Replaceable organization and certification artwork

The timeline and certification section load these local files directly. To use
your own preferred artwork, replace a file while keeping its exact filename:

- `dst.svg`
- `step.png`
- `uoc.png`
- `cifp-cesar-manrique.png`
- `cambridge-english.svg`
- `aws-cloud-practitioner.png`

Transparent SVG or PNG artwork works best. The current files are temporary,
local stand-ins and can be replaced without changing the React components.
