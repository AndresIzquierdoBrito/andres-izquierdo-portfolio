# Editing portfolio translations

The visible copy is split into two TypeScript dictionaries:

- `en/common.ts` — English
- `es/common.ts` — Spanish

Keep the same key structure in both files. Values can be edited directly; the
development server will refresh the translations without needing a restart.

Project section branding lives at `sections.projects.eyebrow`. Certification
copy lives at `education.certs`.
